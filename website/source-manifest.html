Source manifest

The source manifest is a file named skill-manager.json at the root of a source archive. Agent Plugins reads that file to learn the source identity and the packages it can install. Publish the tree as a zip, tar, or tar.gz at a raw HTTPS URL. A source repository is a separate catalog that lists those archives.

Create a compatible source

  1. Make the source tree

    Put skill-manager.json at the top level. Host a zip, tar, or tar.gz of that tree at an https:// artifact URL. Artifact URLs may include a query string and must not include credentials. 

    example-source/
├── skill-manager.json
├── mcp/
│   └── database.json
└── skills/
    └── review/
        └── SKILL.md

  2. Write the manifest

    Set version to 2. Give the source a stable id. Add one package for each installable unit. A package lists one or more skill or mcpServer components. 

    {
  "version": 2,
  "source": {
    "id": "example",
    "name": "Example source",
    "description": "Portable review configuration."
  },
  "packages": [
    {
      "id": "review",
      "components": [
        { "kind": "skill", "id": "review", "path": "skills/review" },
        { "kind": "mcpServer", "id": "database", "path": "mcp/database.json" }
      ]
    }
  ]
}
    Field Rule
    version Required integer. Must be 2.
    source.id 2–16 lowercase letters, digits, or single hyphens. Must begin with a letter. Namespaces package and install names.
    source.name Required display name, 1–120 characters.
    source.description Required description, 1–1,024 characters.
    packages[].id 1–64 lowercase letters, digits, or single hyphens. Unique inside the source.
    packages[].components[].kind skill or mcpServer.
    packages[].components[].id Required when the package has several components. A single component may inherit the package id.
    packages[].components[].path Archive-relative skill directory or MCP document.

    Unknown fields are rejected. Package ids must be unique. Generic file destinations, always-on instruction files, and native agent-plugin@1.0.0 package trees are not accepted.

  3. Write the skill

    A skill path is a directory that contains SKILL.md. The frontmatter name must match the component id. The directory name does not have to match. Agent Plugins rewrites only name to source-id-component-id on install; other keys and the Markdown body are copied through. 

    ---
name: review
description: Reviews a change before it is submitted.
disable-model-invocation: true
---

# Review

Follow the repository's review workflow.
    Field Rule
    name Required. 1–64 lowercase letters, digits, or single hyphens. Must equal the component id.
    description Required non-empty string, at most 1,024 characters.
    disable-model-invocation Optional boolean.

  4. Write the MCP document

    An mcpServer path is a JSON file. Set $schema to the Agent Plugins 1.0.0 MCP schema and declare one or more servers. A stdio command must be a bare executable on PATH. 

    {
  "$schema": "https://agent-plugins.org/schemas/1.0.0/mcp.schema.json",
  "mcpServers": {
    "database": {
      "type": "stdio",
      "command": "npx",
      "args": ["@acme/database-mcp"]
    }
  }
}
    Field Rule
    $schema Required. Must be https://agent-plugins.org/schemas/1.0.0/mcp.schema.json.
    mcpServers Required object with at least one entry. Keys are 1–64 character server names.
    type stdio, streamable-http, or sse.
    command Required for stdio. Bare executable name. No ./bin/server or ${PLUGIN_ROOT}.
    url Required for remote types. https, or http only on localhost.
    sensitive headers Authorization and API-key headers must be ${ENV_NAME}, not a literal secret.

  5. Check paths and limits

    • Directories are copied recursively. Executable permission bits are preserved where supported.
    • Symlinks, special files, globs, commands, hooks, and environment-variable expansion are not supported.
    • The manifest is limited to 1 MB. Selected content is limited to 2,000 files and 50 MB.

  6. Validate and publish

    Check the JSON before committing it:

    jq empty skill-manager.json

    For structural validation, save the v2 JSON Schema beside the manifest and run:

    npx ajv-cli validate --spec=draft2020 --strict=false \
  -s source-manifest.schema.json \
  -d skill-manager.json

    Upload an archive of the tree with every referenced path. List that HTTPS URL in a source repository. In Agent Plugins, add the listed source from Manage Sources. Adding a source validates the tree and makes packages available; it does not install them.
