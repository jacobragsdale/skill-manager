skill-manager.json

A compatible source is a tree with a skill-manager.json file at its root. Publish that tree as a Git repository or as a zip, tar, or tar.gz at a raw HTTPS URL. The manifest publishes portable packages of Agent Skills and MCP servers. Skill Manager projects those packages onto the agents a user enables. A source repository is a separate catalog that lists sources.

Create a compatible source

  1. Make the source tree

    Put skill-manager.json at the top level. Publish the default Git branch with an https:// or ssh:// URL, or host a zip/tar of the same tree at an https:// artifact URL. Artifact URLs may include a query string and must not include credentials. 

    example-source/
├── skill-manager.json
├── mcp/
│   └── database.json
└── skills/
    └── review/
        └── SKILL.md

  2. Write the manifest

    Set version to 2. Give the source a stable id, then add one package for each installable unit.

    {
  "version": 2,
  "source": {
    "id": "example",
    "name": "Example source",
    "description": "Portable review configuration."
  },
  "packages": [
    {
      "id": "review",
      "components": [
        { "kind": "skill", "id": "review", "path": "skills/review" },
        { "kind": "mcpServer", "id": "database", "path": "mcp/database.json" }
      ]
    }
  ]
}
    Field Rule
    version Required integer. Must be 2.
    source.id 2–16 lowercase letters, digits, or single hyphens. Must begin with a letter.
    source.name Required display name, 1–120 characters.
    source.description Required description, 1–1,024 characters.
    packages[].id 1–64 lowercase letters, digits, or single hyphens.
    packages[].components[].kind skill or mcpServer.
    packages[].components[].path Repository-relative skill directory or MCP document.

    Unknown fields are rejected. Package ids must be unique. Generic file destinations and Agent Plugin packages are not accepted.

  3. Check Agent Skill names

    A directory with SKILL.md at its root is treated as an Agent Skill. Its frontmatter name, install id, and source directory name must match.

    ---
name: review
description: Reviews a change before it is submitted.
disable-model-invocation: true
---

    Skill Manager prefixes the installed name with the source id. In the example above, review becomes example-review. The optional disable-model-invocation value must be a boolean.

  4. Check paths and limits

    • Directories are copied recursively. Executable permission bits are preserved where supported.
    • Symlinks, special files, globs, commands, hooks, and environment-variable expansion are not supported.
    • Use forward slashes in ~/ paths. Use a drive-qualified absolute path on Windows.
    • The manifest is limited to 1 MB. Selected content is limited to 2,000 files and 50 MB.

  5. Validate and publish

    Check the JSON before committing it:

    jq empty skill-manager.json

    For structural validation, save the v2 JSON Schema beside the manifest and run:

    npx ajv-cli validate --spec=draft2020 --strict=false \
  -s source-manifest.schema.json \
  -d skill-manager.json

    Commit and push the manifest with every referenced path, or upload an archive of that tree. Add the Git or artifact locator in Skill Manager to check source files, Agent Skill names, destinations, symlinks, portability, and size limits.
