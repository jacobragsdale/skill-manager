Agent Plugins

A desktop program for installing Agent Skills and MCP servers from published sources.

What it does

Agent Plugins reads a source manifest named skill-manager.json from an HTTPS archive and shows you the packages it can install. You can also add a source repository catalog, browse its listed sources, and opt in. You choose what to add or remove.

It installs Agent Skills and MCP configuration into per-user folders. It does not overwrite unmanaged folders or managed installs with local changes.
