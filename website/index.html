Skill Manager

A small desktop program for installing files from Git repositories.

What it does

Skill Manager reads a skill-manager.json file from a Git repository and shows you the files and directories it can install. You choose what to add or remove.

It is useful for installing Agent Skills and other configuration files into per-user folders. It does not overwrite unmanaged folders or managed installs with local changes.
