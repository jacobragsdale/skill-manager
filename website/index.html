Skill Manager

A small desktop program for installing files from published sources.

What it does

Skill Manager reads a skill-manager.json file from a Git repository or a raw HTTPS archive and shows you the packages it can install. You can also add a source repository catalog, browse its listed sources, and opt in. You choose what to add or remove.

It is useful for installing Agent Skills and other configuration files into per-user folders. It does not overwrite unmanaged folders or managed installs with local changes.
