skill-manager-repository.json

A source repository is a catalog that lists sources. It is not installable. Packages appear only after a listed source is added. Publish the document as raw JSON at an HTTPS URL.

Create a compatible catalog

  1. Write the catalog

    Set version to 1. Give the catalog a stable id, then list each source by name, description, and HTTPS archive URL.

    {
  "version": 1,
  "repository": {
    "id": "acme",
    "name": "Acme sources",
    "description": "Official portable sources."
  },
  "sources": [
    {
      "name": "Review workflows",
      "description": "Review skill and database MCP server.",
      "url": "https://nexus.example.com/repository/raw/sources/review-latest.zip"
    }
  ]
}
    Field Rule
    version Required integer. Must be 1.
    repository.id 2–32 lowercase letters, digits, or single hyphens. Must begin with a letter.
    repository.name Required display name, 1–120 characters.
    repository.description Required description, 1–1,024 characters.
    sources[].url HTTPS archive URL. No credentials. Query strings are kept.

    Unknown fields are rejected. Duplicate URLs after canonicalization are rejected. At most 200 listed sources. Nested catalogs are not accepted.

  2. Validate and publish

    Check the JSON before publishing it:

    jq empty skill-manager-repository.json

    For structural validation, save the catalog JSON Schema beside the document and run:

    npx ajv-cli validate --spec=draft2020 --strict=false \
  -s source-repository.schema.json \
  -d skill-manager-repository.json

    Host the JSON at a stable HTTPS URL. In Skill Manager, listed sources appear in Manage Sources by name and description. Select Add on a listed source. Adding a source does not install its packages.
